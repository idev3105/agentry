## Troubleshooting appendix

| Triệu chứng | Nguyên nhân | Fix |
|---|---|---|
| `permission denied (shell:allow-execute)` runtime | Capability file sai/thiếu | T1.3: thêm `9router` / `npx` / `lsof` / `kill` vào scoped allow |
| `Error: spawn 9router ENOENT` | `which("9router")` resolve sai cache | Restart app — `R9Resolved::detect()` chỉ chạy 1 lần lúc startup |
| Click Start, badge mãi "stopped" | 9Router crash ngay | Mở terminal: `9router` — đọc stderr. Hay gặp: port :20128 đã chiếm bởi process khác |
| Click Stop nhưng port vẫn listen | `npx 9router` spawn Node child mà ta không track | `r9::pid_on_port()` fallback đã handle — Stop sẽ kill PID đúng đang listen, không phải PID của npx wrapper |
| `pnpm check` báo `$state is not defined` | File store đặt sai tên | Đổi thành `r9.svelte.ts` (có suffix) |
| `Cannot find module '$lib/stores/r9.svelte'` | Vite chưa rebuild HMR | Restart `mise run tauri` |
| Dashboard mở browser nhưng "connection refused" | 9Router chưa ready | Bấm refresh trong browser sau ~2s; spawn-then-wait loop trong `r9_start` đã chờ tối đa 3s |
| App quit nhưng `9router` vẫn chạy | `kill_on_drop(false)` (intentional) | Đó là feature: cho phép daemon-style outlive app. Stop button vẫn kill được nhờ `lsof`. |
| Nhiều instance Agentry → mỗi instance start riêng | Không có cross-instance lock | OK với scope plan này. Instance B sẽ "adopt" 9router của instance A nhờ `port_open()` check. |
